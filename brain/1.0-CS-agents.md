# 1.0 Agents — Cheat Sheet

## Definition

An **Agent** is a system that leverages an AI model to interact with its environment in order to achieve a user-defined objective. It combines reasoning, planning, and the execution of actions (often via external tools) to fulfill tasks.

## Note: Special tokens and their brackets

The `< >` (**angle brackets**) and `|` in tokens like `<|im_end|>` are just a **naming convention**. They make the string:
- **unlikely to collide** with normal text ("end" is everywhere, `<|im_end|>` almost nowhere);
- **easy to spot** as a control signal when reading a raw prompt.

**The real "specialness" lives in the tokenizer, not in the symbols.** A special token is registered as reserved: it maps to **one single ID**, is never split, and the model learned its meaning during training (end of turn, start of text, …).

**Not every model uses angle brackets** — each family has its own style:

| Model | Examples |
|---|---|
| BERT | `[CLS]`, `[SEP]`, `[PAD]` (square brackets) |
| GPT-2 | `<\|endoftext\|>` |
| Llama 2 | `<s>`, `</s>` (HTML-tag style) |
| Llama 3 | `<\|begin_of_text\|>`, `<\|eot_id\|>` |
| ChatML (Qwen, SmolLM2, …) | `<\|im_start\|>`, `<\|im_end\|>` |

Check it yourself:

```python
from transformers import AutoTokenizer

tok = AutoTokenizer.from_pretrained("HuggingFaceTB/SmolLM2-135M-Instruct")
print(tok.special_tokens_map)        # all special tokens of the model
print(tok.tokenize("<|im_end|>"))    # one single token
print(tok.tokenize("<|im_fine|>"))   # made-up string: split into pieces
```

> **Side note — where the brackets come from**
> - `< >` come from **HTML/XML tags** (`<p>…</p>`); Llama 2's `<s>…</s>` mimics them.
> - `[ ]` in BERT is just its authors' choice, not from HTML.
> - In **Markdown**: `[text](url)` is a link, `[[note]]` a wiki-link (Obsidian); a bare `<word>` may be read as HTML and vanish — wrap placeholders in backticks: `` `<file_name>` ``.
> - `<required>` / `[optional]` in command docs comes from **Unix man pages**: `cp <source> <dest> [options]`.
