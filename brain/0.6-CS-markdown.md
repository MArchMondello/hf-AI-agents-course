# 0.6 Markdown — Cheat Sheet

*Part of hf-AI-agents-course-0-onboarding. Markdown = plain text with a few symbols that a viewer (GitHub, VS Code, Jupyter) turns into formatting. The file stays readable even when nobody renders it.*

## ⭐ The one thing you'll use most

```markdown
**bold**   *italic*   ~~strikethrough~~   `code`
```

## 1. The big idea in one picture

```
notes.md (plain text) ──▶ renderer (GitHub, VS Code preview, Jupyter cell) ──▶ formatted page
   **bold**                                                                       bold
```

| Word | Meaning | Analogy |
| --- | --- | --- |
| **Markdown** (`.md`) | text + symbols for formatting | handwritten proofreading marks |
| **GFM** | GitHub Flavored Markdown: the dialect GitHub uses, adds tables, `~~strike~~`, task lists | a regional dialect of the same language |
| **MDX** (`.mdx`) | Markdown + React components. The HF course is written in it. Not runnable | a book manuscript with layout tags |
| **renderer** | the program that turns symbols into formatting | the printer |
| **preview** | VS Code: `Ctrl+Shift+V` (tab) or `Ctrl+K V` (side by side) | the proof print |

## 2. Text formatting

| Effect | Syntax | Notes |
| --- | --- | --- |
| **Bold** | `**text**` | `__text__` works too; `**` is the convention |
| *Italic* | `*text*` | `_text_` works too |
| ***Bold + italic*** | `***text***` | |
| ~~Strikethrough~~ | `~~text~~` | GFM only, not in basic Markdown |
| <u>Underline</u> | `<u>text</u>` | **no** Markdown syntax: HTML is needed. Avoid it, on the web underline looks like a link |
| `Inline code` | `` `text` `` | file names, commands, variables |

## 3. Structure

```markdown
# --- 1. Headings: one # per level ---
# Title
## Section
### Subsection

# --- 2. Lists: - for bullets, 1. for numbered, 2 spaces to indent ---
- item
  - sub-item
1. first
2. second
- [ ] task to do        (GFM)
- [x] task done         (GFM)

# --- 3. Links and images ---
[text](https://example.com)
![alt text](images/plan.png)

# --- 4. Quote and horizontal rule ---
> a quote
---
```

## 5. Common errors → fixes

| Error | Meaning | Fix |
| --- | --- | --- |
| `**text **` shows the asterisks | a space before the closing `**` | no spaces inside: `**text**` |
| list or table doesn't render | no empty line before it | add an empty line above |
| `my_file_name` turns partly italic | `_` read as italic markers | put it in backticks: `` `my_file_name` `` |
| `~~text~~` shows the tildes | the renderer isn't GFM | accept it, or use `<s>text</s>` |
| `<u>` shows as text | the renderer strips HTML (some do) | use bold or italic instead |
| a `|` inside a table cell breaks the table | `|` is the column separator | escape it: `\|` |
